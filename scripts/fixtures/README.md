its original relative copyright link, so the tests can reproduce Git blob hashes.

- [Upstream CC0 dedication](https://github.com/monad-crypto/MIPs/blob/2a7e18894f1e55fb043080cb8cef15c7f5647768/LICENSE.md)

No network access is needed to read these fixtures or run the tests.
